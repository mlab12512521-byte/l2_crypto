# l2_crypto — CPU-based Layer-2 VPN appliance

Goal: a secure, standards-based Layer-2 (Ethernet) VPN between two sites over an
IP WAN, with crypto on the CPU and a target of ≥ 10 Gbit/s, built on Linux and
mature existing implementations.
